# County-wide Buckinghamshire tutor discovery

User-authorised 10 October 2026: a fresh ten-hour research window covering independent 11+ and primary tutors across Buckinghamshire, including smaller villages and Milton Keynes.

`prepare-plan.py` filters the crawler's county-wide plan against every previous host checkpoint. Its SHA256 search identity excludes presentation metadata and depth, so failed, uncertain and successful paid searches are not repeated. Existing conservative charges and outstanding reservations reduce the shared USD100 ceiling. The new job is capped at USD20 incremental exposure.

Reviewed public web seeds enter the same saved Go crawl graph. The shared limits remain depth two, fifteen external sites per root, five hundred sites and one thousand attempted content pages. School, venue, community, professional and resource pages supply discovery evidence. Candidate exports remain unreviewed research.

The wrapper persists a fixed ten-hour deadline and input digests before credential resolution, then reuses the existing expansion launcher's secret handling and checkpoint resume. Install only on Mac Studio through `scripts/install-launchd-tasks.sh --task tracelearn-tutor-countywide-20261010`. State lives in `state/tracelearn-tutors-20261010-countywide/`; status comes from `tutor-crawler-countywide discover-status --state .../discovery.json`.

Deadline or hard limits can stop discovery. A running process is not proof of completed research. No AI provider calls, emails, domain purchases or tenant impersonation are part of this job.
