# Final five isolated teaching source repairs

One manually kicked Studio job renders the fixed final-five selection, ten compositions,
from a separate pinned runner and final-style-lab project. It preserves active follow-up
helpers and all previously rendered source outputs. Seventeen staged files, five narration
proofs and exact renderer/selector/support/copy hashes are checked before admission.

The registered installer leaves the service inactive. After narration/staging/type checks
pass, an explicit kick starts a durable Studio dispatcher. It waits for all four exact
follow-up receipts and predecessor exit before admitting the final-five renderer. It
archives and removes only a matching, proven-dead predecessor lease, and refuses any
unexpected lease. A failed predecessor or two-hour wait halts without automatic retry.
Standard policy, normal I/O, nice 10, serial four-worker rendering and the 50 GiB floor stay
in force. No API calls or automatic quality approvals. Preserve final outputs and receipts.
