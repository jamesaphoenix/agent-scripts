# Smart Cub isolated teaching corrections

One authorised Studio-only job renders four corrected teaching sources from the isolated
style-lab project. The wrapper pins the staging manifest, all eleven staged file hashes,
both voice proofs and the renderer implementation. It uses Node22, nice10, Standard
process policy and normal I/O, one render with four workers, and the existing shared
founder host lease and50GiB floor. No paid APIs, helper activation or quality approval.

Install through the launchd registry. Installation stays inactive, with RunAtLoad and
KeepAlive false. Run the installed run.sh with --check before the manual kick.
The dispatch status is workflow/teaching-corrections-dispatch-status.json under the task
run root. Logs are evidence/teaching-corrections-dispatch-{stdout,stderr}.log.
Project output status is teaching-repairs/style-lab/out/correction-render-status.json.
Finished or failed jobs need explicit reconciliation before restart. Preserve final
outputs, receipts, source proofs and review evidence. Remove only this job's stopped
resources after completion and review.
